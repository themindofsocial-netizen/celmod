// |CelMod| emblems and hats.
//
// The section name is the item's id: it is what players type (!emblem fire) and what is stored in
// their inventory and builds, so do not rename an id once players own the item.
//
// Shared keys:
//   name        Display name.
//   model       Model path. Custom files must also be listed in data/celmod/downloads.txt.
//   color       "R G B A" tint. Use "255 255 255 255" to leave the model's own texture untouched.
//   dropweight  Chance weight in emblem drops and "random" rewards. 0 = never drops.
//
// Emblem keys:
//   skin        Skin number of the model. models/celmod/phys8.mdl has 15 (0 to 14, materials s1 to s15).
//   scale       Size of the emblem cel in the world. The collision box does not scale with it.
//   handscale   Size of the copy other players see in the owner's right hand.
//   handoffset  "forward left up" from the right hand, to line the copy up with the hand.
//   handangles  "pitch yaw roll" of the copy relative to the hand.
//   power       Used with primary fire, which can be held down (cooldown and range apply to all):
//               flash     Blinds players facing you. duration = seconds blinded, range.
//               smog      Smoke cloud where you aim (one at a time); players in it cough and take "value" damage a second.
//               nuke      A headcrab canister falls where you aim. value = impact damage. See cm_nuke_wrecks_builds.
//               shot      Hurts a player. value = damage, dmgtype = burn/drown/poison/shock/dissolve/
//                         energy/generic, ignite = seconds the player is set on fire (optional).
//               flamethrower  A short stream of flames. value = damage per hit, ignite = seconds on fire.
//               spray     A harmless beam.
//               medic     Heals the player you aim at by "value". Right click heals you.
//               magnitude Throws loose physics props and players. value = force. Right click pulls.
//               portal    Places a portal. Right click places the other one; walk in to cross.
//               chaos     Sets fire to players within "value" units of where you aim for "duration".
//               blast     Explosion where you aim. value = magnitude.
//               demon     A tower of dark power rises where you aim (value = damage). Right click shakes nearby screens.
//               blink     Teleports you to where you aim.
//               Passive powers:
//               speed     Run faster. value = speed multiplier.
//               sprint    Sprint never runs out.
//               gravity   Changes your gravity. value = multiplier (0.5 = half).
//               jump      Jump higher. value = upward jump speed (a normal jump is about 200).
//               feather   Fall slowly. value = fastest falling speed.
//               heal      Regenerate health. value = health per second.
//               armor     Regenerate suit power. value = suit power per second.
//               resist    Take less damage. value = damage multiplier (0.5 = half).
//               phase     Hold right click to pass through walls (playercolor makes the holder see-through green).
//               cloak     Turn translucent. value = how visible you stay (0 to 255).
//               drain     Hurts its own holder. value = damage per second.
//               gold      Earn money. value = CL per minute while enabled.
//               none      Cosmetic only.
//   speed       Any emblem can also carry a speed multiplier, on top of its power.
//   jumpboost   Upward speed of a jump while held (a normal jump is about 200).
//   falldamage  Fall damage multiplier while held (0.4 = 40%).
//   playercolor "R G B A" tint of the holder while held.
//   glow        1 = the emblem glows.
//   upgradesto, upgradecost  At the Power Booth, this many of the emblem turn into one of the other emblem.
//   fx          What a shot looks like:
//               flame, ice, water, energy, smoke, orb  Sprites that fly to the target ("sprite").
//               model                                  A model that flies to the target ("sprite" is a .mdl).
//               spray                                  A burst of sprites thrown forward ("sprite").
//               laser, plasma, rainbow, beam           Beams. beam is the default.
//               none                                   Nothing.
//               Layered styles (each emblem has its own; any emblem can use any of them):
//               snowstorm frostline shards waterbolt wave acidglob venomspiral arc pulse laser static
//               gemtwin gemprism gemstar gemorbit plasmaflow ion prism lava embers comet glitch nova
//               supernova thunder chainspark healbeam lovebeam rainbowspray aurora mist sandstorm
//               tractor geyser gravwell tornado
//   aura        What the holder looks like while the emblem is held out (cm_emblem_aura 0 turns them off):
//               flames frost drip sparks thunder glint prism smoke glitch speed bolt dust float bounce
//               wisp halo shield gold drain demon radiation vortex blink sun eclipse embers confetti
//               stars rising pulse dusk code crackle haze void radiant phase heart, or none.
//   sprite      Sprite material used by fx, e.g. "sprites/flamelet1.vmt".
//   slow        "shot" only: seconds the target is slowed and tinted blue.
//   knockback   "shot" only: how hard the target is shoved back.
//   secondary   Right click attack: fireball (flies and explodes), icestorm (burst of ice that hurts and
//               slows), bigshot (one heavy bolt with recoil) or none.
//               secondaryvalue = its damage or blast size, secondarycooldown = seconds between uses.
//   beamcolor   "R G B A" color of a shot power's beam. Defaults to "color".
//   Powers only work while the emblem is enabled and the gravity gun is the weapon in hand.
//
// Hat keys:
//   skin        Skin number of the model.
//   offset      "forward left up" from the player's eyes.
//   angles      "pitch yaw roll" relative to the player's head.
//   scale       Model scale. Leave it at 1.0: scaled models do not show in HL2DM.
//
// Big emblems: every emblem automatically has a big version ("<id>_big", e.g. fire_big) made at the Power Booth
// from several copies. It uses models/celmod/bhys8.mdl and is about half again as strong.
//
// Weapon (celwep) keys:
//   base        The stock weapon the player is handed, e.g. weapon_crowbar, weapon_stunstick, weapon_pistol.
//   damage      Damage multiplier for hits made with it.
//   model       Shown as the cel, and in the holder's hand to other players (handscale, handoffset, handangles).
//   The holder's own first person view stays the stock weapon.
//   customgun   With the Custom Guns plugin installed: the Custom Guns weapon this celwep is, e.g. weapon_cm_axe
//               (scripts/weapon_cm_axe.txt). It is then a separate weapon with its own view model, several can be
//               carried at once, and base/damage/hand keys are not used. Without Custom Guns, base is used instead.
//   attack      melee (default): a swing. ranged: a shot at whatever is aimed at, looking like its "fx" (range,
//               fx, sprite, beamcolor). melon: throws a watermelon ("range" is how fast).
//   hitdamage   Damage of one hit (Custom Guns celweps). hitrange = reach, refire = seconds between swings.
//   ignite, slow  Seconds a hit sets a player on fire, or slows them.
//   digs        Emblem ids a hit on the ground can dig up. Most digs find junk; see cm_dig_chance,
//               cm_dig_emblem_chance, cm_dig_money_chance, cm_dig_money_min and cm_dig_money_max.
//
// PlayerModels: name, model and price. A price of 0 is free for everyone.
//   admin       Admin flags (e.g. "b"). Admins with them own the model; with price 0 nobody else can buy it.
//   materials   A folder whose files are all sent to players, for custom models, e.g. "materials/models/player/mymodel".
//   A model's own files (.mdl, .vvd, .phy, .vtx) are sent automatically when the server has them.
//   Admins can also give or take any model with !givemodel and !takemodel.
