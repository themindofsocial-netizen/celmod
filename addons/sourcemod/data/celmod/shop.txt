//     name         Display name.
//     price        Price in CL.
//     stock        Optional: how many can ever be sold. Sold counts live in data/celmod/shopstock.txt.
//     category     Heading in the shop, e.g. "Rare Cels" or "Discontinued Props".
//     description  Optional one-liner shown in the web shop.
//     spawn        "classname|model". Leave it out if the alias is already in spawns.txt; it then
//                  stops being free for everyone and becomes buy-only.
//     season       Optional: a key from "Seasons" (at the bottom). The prop is only sold while that season
//                  is on; players who bought it can spawn it all year.
//
// Collectibles: emblems, hats or weapons from collectibles.txt for sale.
//     "key" { "kind" "hat" "id" "<collectible id>" "price" "..." }  plus stock, category, description,
//     and "repeatable" (default 1 for emblems, which stack, 0 for hats and weapons).
//
// Player models are listed automatically from the "PlayerModels" in collectibles.txt (price there).
